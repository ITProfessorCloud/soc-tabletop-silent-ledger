# Silent Ledger SOC Tabletop

A single page HTML tabletop exercise called Operation Silent Ledger, built for training SOC analysts on identity compromise and business email compromise scenarios.

Hosted here as index.html and served through GitHub Pages, then embedded on itprofessor.cloud inside an iframe so the exercise keeps its own styling and does not clash with the blog theme.

Built by IT Professor. Training simulation only, no real customer data.
